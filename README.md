# Book Management System

## About the Project
A simple web-based Book Management System that helps users manage and organise books.

## Features
- View the existing book collection.
- Add new books using an Add New Books form.
- Organise book information.
- Simple and user-friendly interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- `index.html` – Main webpage structure.
- `style.css` – Styling and layout.
- `script.js` – JavaScript functionality.
- `README.md` – Project documentation.

## Installation and Usage
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Future Improvements
- Edit and delete books.
- Search and filter books.
- Store book information permanently.
